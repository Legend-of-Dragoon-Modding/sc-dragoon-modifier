# About
Dragoon Modifier for [Severed Chains](https://legendofdragoon.org/projects/severed-chains/) is the port of the emulation modding tool [Dragoon Modifier](https://github.com/Legend-of-Dragoon-Modding/Dragoon-Modifier) to the Severed Chains platform. 
Dragoon Modifier is a simple tool that anyone can use with a spreadsheet editor to make their own custom difficulties. 
It comes with my prepackaged difficulty preset with additional mods.

Dragoon Modifier currently supports Severed Chains 3.0.

### Installation

Drag and drop it into the Severed Chains mods folder.

**Please note any difficulties created with Dragoon Modifier should only need to contain the new folder in a ZIP. It should not contain a repackaged Dragoon Modifier ever.**

A repackaged Dragoon Modifier is a ZIP file you downloaded that contains a JAR file of sc-dragoon-modifier-x.x.jar that was not downloaded from this github repository.

### Creating your own difficulties with Dragoon Modifier
To create a new difficulty select a base version out of the five existing configurations ("Retail NA", "Retail JP", "Japan Demo", "Hard Mode", "Retail NA + Hard Bosses") copy that folder, paste it and rename it to your new difficulty.

You can start editing the CSVs now in your newly created folder.
Characters Additions, base stats, character configuration, dragoon "addition", dragoon stats are all in their individual character folders.
The addition list, equip stats, level locker, monster rewards, monster stats, archer sp gain, shop items, spells, and thrown item stats are all in the main folders of the difficulty. 

A guide to all of this can be found on the Wiki.
